# Voice Profile · 南橘写作风格基线

> 首版（2026-08-29），基于第 1 篇归档样本《pi 解剖》（writing-samples/2026-08-29-pi-agent.md）提炼。
> 样本量 1 篇，字段置信度低；每归档一篇增量修订，≥3 篇后再谈稳定。

## 当前基线（初版）

| 字段 | 值 | 备注 |
|---|---|---|
| 平均句长 | 约 22-28 字/句，长短交替明显 | 抽样自正文叙述段 |
| 短句占比 | 约 12%（<10 字句） | 达契约 ≥10% |
| 高频转场词 | 「后来」「当然」「顺带一提」「再说回来（少用）」 | |
| 第一人称密度 | 每千字约 2-3 处「我」，集中在方法声明与核查现场 | 克制型 |
| 比喻频率 | 每千字 ≤0.5 个，全篇 ≤3 个家族 | 加法题/底盘整车，无延伸链 |
| 小标题风格 | 「短语 + (英文标签)」，4-8 字，不用问句 | |
| 数字密度 | 高，每千字 ≥4 个具体数字/版本号 | 技术核查型写作特征 |
| 收尾方式 | 判断式，落在具体事实上 | 禁模板展望 |
| 括号插入语 | 每千字约 1-2 处，多用于口径标注 | |
| 中英混排 | 技术名词保留英文，首次给中文说明；引语保留英文原句+括注 | |
| 情绪强度 | 克制，体感型表达 2-3 处/篇（"我以为是写错了"） | |
| 标点习惯 | 破折号 0-2 处/篇；正文冒号 ≈2/千字（上限） | 写作时注意压冒号 |

## 使用规则

1. Phase A 的 S3 写作、S4 的 R4/R5 审读先读本文件。
2. 样本频率优先于 human-voice 契约上限（如样本破折号多则按样本保留）。
3. 每次归档新终稿后，增量 diff 本文件（句长分布/新增口头禅/口径变化），保留历史备注一行。
